## 🐛 Troubleshooting

**Images not showing?**
- Run `python create_placeholder_images.py` again
- Check `backend/media/` folder exists
- Verify Django media serving is configured

**Can't login?**
- Verify SQL was executed successfully
- Check credentials: `amina.demo@gmail.com` / `password123`
- Check database connection

**Missing data?**
- Re-run `demo_seed_data.sql`
- Check sequences were updated
- Verify no SQL errors
